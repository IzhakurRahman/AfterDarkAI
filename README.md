# AfterDark AI — Android starter

This is a **starter Android Studio project**, not a finished APK. It includes:
- Dark-themed chat UI
- Character selector
- Self-declared 18+ entry gate
- Demo chat messages

## Build
1. Install Android Studio (recent stable version).
2. Open this folder as a project.
3. Let Gradle sync complete.
4. Select **Build → Build APK(s)**.

## Live AI connection
The chat currently runs in demo mode. To add online AI, choose a provider whose terms explicitly permit your intended adult-oriented use, then implement its API through a secure backend. Do **not** put a private API key in the Android app; APKs can be reverse-engineered.

A genuinely free service may impose quotas, content restrictions, or change its free tier. This project does not claim to provide unlimited free AI.

## Safety and release checklist
- A checkbox is not robust age verification.
- Add server-side age assurance appropriate to the launch country and distribution channel.
- Keep roleplay fictional, consensual, and adults-only.
- Add reporting, blocking, data deletion, privacy policy, and secure retention controls before public release.
- Review Google Play and AI-provider policies before distribution.
